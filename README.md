## 🚀 Fonctionnalités Principales

- **Panier d'achat** : Ajoutez facilement des produits au panier.
- **Liste de souhaits** : Sauvegardez vos produits favoris.
- **Paiement sécurisé** : Intégration de **CinetPay** pour des transactions fluides.
- **Chat avec un commercial** : Discutez en direct pour des questions sur un produit.
- **Passation de commande** : Processus simple et intuitif.
- **Suivi de commande en temps réel** : Suivez le statut de votre commande jusqu'à la livraison.
- **Support du mode sombre/clair** : Adaptation automatique à vos préférences système.
- **Multilingue** : Interface disponible en **Français** et **Anglais**.

## 📲 Téléchargement de l'APK

La dernière version de l'APK est disponible dans les [Releases GitHub](https://github.com/Mondo67244/Kanjad/releases/latest)

**Étapes d'installation :**
1. Téléchargez le fichier `.apk` depuis la release la plus récente.
2. Sur votre appareil Android :
   - Allez dans **Paramètres > Sécurité** (ou **Confidentialité**) et activez **Sources inconnues** / **Installer des apps inconnues** pour votre navigateur.
3. Ouvrez le fichier téléchargé et installez l'application.
4. Entrez dans l'univers de Kanjad !

⚠️ **Avertissement** : Installez uniquement depuis cette source officielle pour éviter les risques de sécurité.

- **Shopping Cart**: Easily add products to your cart.
- **Wishlist**: Save your favorite products.
- **Secure Payment**: Integration with **CinetPay** for smooth transactions.
- **Chat with a Sales Representative**: Live chat for product-related questions.
- **Order Placement**: Simple and intuitive process.
- **Real-time Order Tracking**: Follow your order status all the way to delivery.
- **Dark/Light Mode Support**: Automatically adapts to your system preferences.
- **Multilingual**: Interface available in **French** and **English**.

## 📲 APK Download
The latest APK version is available in the [GitHub Releases](https://github.com/Mondo67244/Kanjad/releases/latest).

**Installation Steps:**
1. Download the `.apk` file from the most recent release.

   - Go to **Settings > Security** (or **Privacy**) and enable **Unknown Sources** / **Install unknown apps** for your browser.
